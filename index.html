How it works

Where each answer actually comes from

Nothing gets scraped from the web while you wait for an answer, that would be too slow and too unreliable to trust. Instead, the underlying law is loaded ahead of time, and every answer is limited strictly to what's already on file.

1. Find the relevant law

Your question is matched against the statutes and regulations already loaded: federal rules, DEA guidance, and any state regulations that have been added.

2. Answer only from that law

The answer is written strictly from those matching sections. It never fills in gaps from general knowledge, and if nothing on file actually covers your question, it says so instead of guessing.

3. Show you the source

Every answer comes with citations you can click. Doing so opens the exact passage it's based on, with a link to that same passage on the original source page so you can double-check the wording yourself.

4. Flag disagreements

When federal law and a state's law, or two states, genuinely disagree on the same question, the answer says so directly and notes which one is stricter, rather than quietly picking one.
